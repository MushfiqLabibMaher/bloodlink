# BloodLink

**One platform. People ready to help.**

BloodLink is a responsive front-end concept for bringing blood donors and people seeking blood together, with NGOs and blood centers included in the same coordination platform.

## Project links

- [Open the BloodLink Figma prototype](https://www.figma.com/proto/mBpMNJSGoHuBTNdPuGcxkO/BloodLink_Prototype?node-id=460-955)

## Demo

Open `index.html` in a browser. No installation or build step is required.

The demo includes searchable, filterable sample blood requests, an interactive request form, and a donor sign-up form. Form submissions are saved in the current browser's local storage so they remain visible during a local demo.

## Platform concept

- **Donors** can find requests by blood group and location.
- **Recipients and families** can post a blood request and find potential matches.
- **NGOs** can help coordinate outreach and community support.
- **Blood centers** can participate in the same coordination network.

## Scope and safety

This repository is a front-end demonstration, not a live blood-matching or emergency-response service. Example listings are fictional. It does not contact donors, NGOs, hospitals, or blood centers, and it does not verify availability, eligibility, or medical compatibility. Blood donation and transfusion must always be coordinated with qualified medical professionals and licensed blood centers.
